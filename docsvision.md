# StudyOS

An AI-powered study management system built specifically for students.

## Goal

Help students improve their marks by intelligently planning their studies.

Instead of simple reminders, the app generates a personalized daily plan based on:

- School timetable
- Coaching schedule
- Homework
- Upcoming tests
- Weak subjects
- Available study time

## Version 1 Features

- Dashboard
- Calendar
- Task Manager
- Study Timer
- Marks Tracker
- Analytics

## Future Features
