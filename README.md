# 🚀 StudyOS – Your AI-Powered Study Operating System

> Plan Smarter. Study Better. Achieve More.

StudyOS is an AI-powered academic productivity platform designed to help students manage their entire study journey in one place. It combines intelligent scheduling, task management, revision planning, academic analytics, and AI-driven recommendations to help students stay organized and perform at their best.

Built for students preparing for **CBSE, ICSE, State Boards, JEE, NEET, CUET**, and other competitive examinations.

---

## ✨ Features

- 🤖 AI-powered daily study planner
- 📅 Smart calendar for school, coaching & exams
- ✅ Task & homework management
- 📚 Subject & chapter progress tracking
- 📊 Study analytics & productivity reports
- 📝 Marks and exam performance tracker
- ⏱️ Focus Mode with Pomodoro timer
- 🔄 Intelligent revision scheduler
- 🔔 Smart reminders & notifications
- ☁️ Secure cloud synchronization
- 🔐 Authentication with Supabase

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/StudyOS.git
```

Navigate to the project:

```bash
cd StudyOS
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file in the root directory.

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
